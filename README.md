## 更新「我最近在忙什麼」

只要改 `assets/now.json`，不用動 `index.html`：

- `updated`：更新日期（網站會自動顯示「今天／昨天／N 天前更新」）
- `status`：現在在忙什麼（中英各一句）
- `post`：最新一篇貼文的文案、日期、底圖（`art.mascot` 或 `art.image`）和虛擬朋友留言
- `log`：最近做了什麼，新的放最上面，留 3～5 筆就好
